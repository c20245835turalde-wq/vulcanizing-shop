# Jayson Turalde


**Live site:** Not published yet.


## About


This website introduces a local vulcanizing shop and its tire services. It helps
drivers learn about tire patching, tire changes, and inspections, then send an
inquiry through the contact form.


## Design System


### Palette (60-30-10)


| Role | Color | Used for |
|---|---|---|
| Dominant | `#f5f6f2` (light) / `#202820` (dark) | Page and section backgrounds |
| Secondary | `#174c3a` | Navigation, buttons, and emphasized sections |
| Accent | `#c8f169` | Highlights, links, and progress indicator |


### Visual style


**Style chosen:** Clean, responsive service-business layout.


**Why I chose it:** The straightforward design makes it easy for customers to
find tire services and contact the shop.


### Contrast check


Light-mode body text `#020f2c` on background `#f5f6f2`  
Contrast ratio: 17.5:1 (WCAG AA requires at least 4.5:1 for normal text)  
Tool used: WCAG relative luminance contrast-ratio formula
